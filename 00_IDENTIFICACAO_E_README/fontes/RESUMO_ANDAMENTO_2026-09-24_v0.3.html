1. Sistema escolhido

Sistema web de gestão de uma pequena produção de alimentos, desenvolvido anteriormente por um integrante. Usa Django REST Framework e PostgreSQL no backend e Vue 3 no frontend. Cobre clientes, produtos, vendas, recebíveis (fiado), pagamentos, compras, produção e fechamento mensal. Os testes usam somente uma cópia local, com banco próprio e dados fictícios.

A 2ª opção avaliada foi o GreenOps Profiler (TCC do grupo), descartada por não ter interface web nem formulários suficientes (seção 5.3). A comparação completa está na Ficha do Apêndice A (P01).

2. O que está pronto

  • Estrutura: pasta P2_TQS_2026_CC_GRUPO13_SABORINO com as 17 subpastas da seção 11.3.
